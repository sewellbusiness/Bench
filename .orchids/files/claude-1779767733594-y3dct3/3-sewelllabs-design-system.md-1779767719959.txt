# Sewell Labs — Design System Reference

## Brand Overview

Sewell Labs uses a clean, professional dark/light dual-mode design. Dark backgrounds for hero and footer sections, light backgrounds for content sections. The primary accent color is orange throughout both modes.

---

## Color Tokens

### Sewell Labs Brand
| Token | Hex | Usage |
|---|---|---|
| `sewell.orange` | `#F5A623` | Primary CTA, accents, links, badges, icons |
| `sewell.dark` | `#111827` | Hero bg, footer bg, dark sections |
| `sewell.text` | `#1E1E2E` | Primary body text on light backgrounds |
| `sewell.muted` | `#6B7280` | Secondary/supporting text |
| `sewell.bg` | `#F8F9FA` | Light section backgrounds |
| `sewell.border` | `#E5E7EB` | Card borders, dividers |

## Typography

### Fonts
| Role | Font | CSS Var | Fallback |
|---|---|---|---|
| Display / Headings | **Sora** | `--font-sora` | sans-serif |
| Body / UI | **DM Sans** | `--font-dm-sans` | sans-serif |

- `font-display` — used for all headings, eyebrows, labels, buttons, badges, nav links
- `font-body` — used for paragraph text (default body font)

### Type Scale (Tailwind)
| Class | Size | Usage |
|---|---|---|
| `text-7xl` | 4.5rem | Hero h1 (desktop) |
| `text-6xl` | 3.75rem | Hero h1 (tablet) |
| `text-5xl` | 3rem | Hero h1 (mobile) |
| `text-4xl` | 2.25rem | Page h1, section h2 |
| `text-3xl` | 1.875rem | Section h2 |
| `text-2xl` | 1.5rem | Feature h3 |
| `text-xl` | 1.25rem | Hero subheadline, lead text |
| `text-lg` | 1.125rem | Body emphasis |
| `text-base` | 1rem | Standard body |
| `text-sm` | 0.875rem | UI labels, secondary text |
| `text-xs` | 0.75rem | Eyebrows, badges, captions |

### Eyebrow Style
All section eyebrows follow this pattern:
```
text-xs font-semibold font-display uppercase tracking-widest text-sewell-orange
```
Example: "FOLIO FEATURES", "OUR MISSION", "TRUEPOST"

## Spacing & Layout

### Max Widths
| Class | Width | Usage |
|---|---|---|
| `max-w-7xl` | 80rem | Wide content sections |
| `max-w-5xl` | 64rem | Standard content sections |
| `max-w-4xl` | 56rem | Hero, page headers |
| `max-w-3xl` | 48rem | FAQ, narrow content |
| `max-w-2xl` | 42rem | Body copy, subtitles |
| `max-w-xl` | 36rem | Tight callouts |

### Section Padding
- All sections: `py-24 px-4 sm:px-6 lg:px-8`
- Hero section: `pt-24 pb-16` (inside content div)
- Page heroes: `py-24`

### Grid Patterns
- 2-column: `grid grid-cols-1 lg:grid-cols-2 gap-16`
- 3-column: `grid grid-cols-1 sm:grid-cols-3 gap-6`
- 4-column: `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-5`

## Section Backgrounds (Pattern)

| Background | Color | Typical Use |
|---|---|---|
| Dark | `bg-sewell-dark` (#111827) | Hero, page headers |
| Navy | `bg-folio-navy` (#1B2A4A) | CTA banner, product showcase |

## Components

### Button
Shape: `rounded-full`
Font: `font-display font-semibold`
Transition: `transition-all duration-200`

| Variant | Background | Text | Hover |
|---|---|---|---|
| `primary` | `#F5A623` (orange) | white | `amber-500` |
| `secondary` | `#111827` (dark) | white | `gray-800` |
| `ghost` | transparent | white | `white/10` bg |

| Size | Padding | Font |
|---|---|---|
| `sm` | `px-4 py-2` | `text-sm` |
| `md` | `px-6 py-3` | `text-sm` |
| `lg` | `px-8 py-4` | `text-base` |

### Badge
Shape: `rounded-full`
Font: `text-xs font-semibold font-display`
Padding: `px-3 py-1`

| Variant | Background | Text | Border |
|---|---|---|---|
| `orange` | `#F5A623` solid | white | `#F5A623` |
| `blue` | `blue/10` | `sewell-blue` | `blue/20` |
| `green` | `green-500/10` | `green-600` | `green-500/20` |
| `gray` | `gray-100` | `gray-500` | `gray-200` |
| `red` | `red-500/10` | `red-600` | `red-500/20` |
| `yellow` | `yellow-500/10` | `yellow-600` | `yellow-500/20` |

### Cards
Standard card: `bg-white rounded-2xl border border-gray-100 shadow-sm hover:shadow-md transition-shadow`
Dark card: `bg-white/5 rounded-xl border border-white/5`

### Section Header (SectionHeader component)
- Eyebrow: `text-xs font-semibold font-display uppercase tracking-widest text-sewell-orange mb-3`
- Title: `text-3xl md:text-4xl font-display font-bold text-sewell-dark`
- Subtitle: `text-gray-500 text-base max-w-2xl mx-auto`
- Alignment: centered by default

## Navigation

### Navbar
- Height: `h-16` (fixed, `pt-16` offset on all pages)
- Transparent on hero (dark bg), white + shadow on scroll
- Logo: `h-24 w-auto` with `-mx-3` offset
  - Dark bg: `logo-wh-or.png` (white/orange)
  - Light bg: `logo-bl-or.png` (blue/orange)
- Nav links: `text-sm font-display font-medium`
- CTA button: primary variant, `size="sm"`, "Get Started with Folio"

### Footer
- Background: `bg-sewell-dark`
- Logo: `logo-wh-or.png` `h-24 w-auto`
- 4-column link grid: Folio / Company / Legal + newsletter
- Copyright: `© 2026 Sewelllabs. All rights reserved.`
